Entry for the [make.fun bounty "The Printer Finally Answers"](https://make.fun/bounty/u-mang-the-printer-finally-answers-8fbf0907).

The office printer finally speaks back to the paper jams, the cryptic
error codes and the thumps — one line, in the machine's own weary,
literal, faintly passive-aggressive voice.


## The line

> STATUS: 41,209 pages printed, 312 jams, 214 thumps. Error code E-YOU: operator error — please stop thumping me, I remember everything.

## Run

```sh
python3 main.py   # writes /output/entry.txt
```

`main.py` writes exactly that one line (134 characters) to
`/output/entry.txt` as UTF-8 text.
